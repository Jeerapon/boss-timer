# Boss Timer – Lineage2M Attendance

เว็บบันทึกการลงบอส/กิจกรรมแคลน สแกนหน้าจอ Participant แล้วส่งข้อมูลไป Google Sheet

- `index.html` – ตัวเว็บ (ไฟล์เดียว)
- `apps-script-Code.gs` – โค้ดฝั่ง Google Apps Script (ไม่ได้ใช้บน Render ใช้วางใน Apps Script)
- `render.yaml` – ตั้งค่า Render Static Site

อัปเดตเว็บ: แก้ `index.html` แล้ว commit ขึ้น GitHub → Render จะ deploy ใหม่ให้อัตโนมัติ
